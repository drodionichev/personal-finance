# Personal Finance

Консольное приложение для учёта личных финансов: доходы и расходы по категориям, бюджеты и предупреждения о перерасходе.

## Возможности

| Команда | Что делает |
|---|---|
| `register` | регистрация по логину и паролю |
| `login` | вход в аккаунт |
| `logout` | выход из аккаунта |
| `income` | добавить доход в категорию |
| `expense` | добавить расход в категорию |
| `budget` | установить лимит на категорию |
| `stats` | общий доход, расходы, баланс и остаток по каждому бюджету, доходы и расходы по категориям |
| `help` | показать справку с командами |
| `exit` | сохранить данные и выйти |

**Предупреждения.** После каждого расхода программа проверяет:
- превышен ли бюджет по категории;
- не стали ли расходы больше доходов (баланс ниже нуля).
- потрачено 80% лимита
- баланс равен нулю

Неправильный ввод (не число, пустая категория, сумма ≤ 0) не роняет программу: она показывает понятное сообщение.

## Структура проекта

| Пакет | Ответственность |
|---|---|
| `model` | данные и расчёты: `User`, `Wallet`, `Operation` |
| `service` | логика: `AuthService` (регистрация и вход), `FinanceService` (расходы и предупреждения) |
| `storage` | сохранение и загрузка данных: `FileStorage` |
| `cli` | общение с пользователем: `ConsoleApp` (команды), `Main` (точка входа) |

Только `ConsoleApp` читает ввод и печатает в консоль. Сервисы ничего не выводят: они возвращают результат или кидают исключение.

## Запуск

Требования: Java 21, Maven.

    mvn package
    java -cp target/classes ru.drodionichev.finance.cli.Main

Или открыть проект в IntelliJ IDEA и запустить класс `Main`.

## Как пользоваться сервисом

При запуске программы пользователя встречает приветственное сообщение: "Здравствуйте, введите help, чтобы ознакомиться с командами сервиса"
Пользователь может ввести "help"

    > help
    register - регистрация по логину и паролю
    login - вход в аккаунт по логину и паролю
    logout - выход из аккаунта
    income - добавить доход в категорию
    expense - добавить расход в категорию
    budget - установить лимит на категорию
    stats - отобразить общий доход, расходы, баланс, остаток по каждому бюджету, доходы и расходы по категориям
    exit - сохранить данные и выйти
    help - показать справку c командами

После ознакомления, пользователь может воспользоваться любой из команд:


    > register
    Логин: Sith
    Пароль: 1234
    Пользователь создан
    
Теперь пользователь может пользоваться сервисом, ему нужно войти:

    > login
    Логин: Sith
    Пароль: 1234
    Добро пожаловать, Sith

Пользователь может положить доход:

    > income
    Введите категорию: Зарплата
    Введите сумму: 50000
    Доход добавлен в размере: 50000.0 в категорию: Зарплата

Пользователь может установить бюджет для категории затрат:

    > budget
    Введите категорию для бюджета: Развлечения
    Введите лимит для категории: 15000
    Лимит на: Развлечения установлен в размере: 15000.0
    
Пользователь может потратить больше бюджета:

    > expense
    Введите категорию: Развлечения
    Введите сумму: 30000
    Расход добавлен в размере: 30000.0 в категорию: Развлечения
    В категории: Развлечения затраты больше установленного лимита в: 15000.0

Пользователь может увидеть статистику:

    > stats
    Общий доход: 50000.0
    Общие расходы: 30000.0
    Баланс: 20000.0
    Доходы по категориям: 
       Зарплата: 50000.0
    Расходы по категориям:
        Развлечения: 30000.0
    Бюджеты: 
    Категория: Развлечения, Лимит: 15000.0, Осталось: -15000.0
    
## Тесты

24 юнит-теста на JUnit 5 для `Wallet`, `AuthService` и `FinanceService`: позитивные, негативные и граничные случаи.

    mvn test

Тесты автоматически запускаются в GitHub Actions при каждом пуше в `main`, собранный `.jar` сохраняется как артефакт.

## Хранение данных

Данные загружаются из файла `finance.dat` при запуске и сохраняются после каждого изменения и при выходе. Файл создаётся локально и добавлен в `.gitignore`. Сохранение и загрузка данных: интерфейс Storage, реализация FileStorage
